One add command

Local and remote sources follow one path.

This direct-only workflow is user-owned and manual. Add UTF-8 text files up to 16 MiB through files, directories, local Git worktrees, or HTTPS URLs. On Windows, add individual files; directory imports are unavailable. Convert binary documents to text before adding them. Git pointers record a repository address, exact commit, and repository-relative path; their pinned revision must remain available in a local binding. Network Git fetching is disabled. Local non-Git paths remain private behind a logical binding.

01

Initialize

graphoxide wiki init --authoring-profile config/authoring-input.json

The authoring profile is secret-free. Provider credentials remain outside the repository.

02

Add

graphoxide wiki source add docs/ api.md --allow-model-egress

New entries publish immediately as clearly marked provisional content.

03

Add remote

graphoxide wiki source add --allow-network --allow-model-egress https://docs.example.test/spec.md

Remote transfer and transient authoring egress are explicit for each command.

Explicit lifecycle

Refresh, review, inspect, or retire.

Nothing becomes reviewed merely because it was added. Refresh is the only operation that advances a source pin. Review is an explicitly invoked AI quality pass; local confirmation is a separate action after review.

  • ✓ Changed source: provisional again
  • ✓ Unavailable source: visible stale/error state
  • ✓ Review: configured AI quality pass, then separate human confirmation
  • ✓ Retire: removes Graphoxide-owned pointer artifacts only
source lifecycle
$ graphoxide wiki source status --json
$ graphoxide wiki source refresh src:SOURCE_ID --allow-model-egress
$ graphoxide wiki source refresh src:SOURCE_ID --allow-network --allow-model-egress
$ graphoxide wiki source review src:SOURCE_ID --allow-model-egress
$ graphoxide wiki source confirm src:SOURCE_ID
$ graphoxide wiki source retire src:SOURCE_ID
Navigate locally

One stable preview for discovery.

graphoxide wiki live serves taxonomy routes, topic pages, source entries, provisional content, reviewed content, and stale/error state on a loopback port. It never exposes source bytes or private filesystem roots. Install Hugo 0.165.0 separately and point GRAPHOXIDE_HUGO_BINARY to its executable.

$ export GRAPHOXIDE_HUGO_BINARY=/absolute/path/to/hugo
$ graphoxide wiki live . --port 1313 --open
MCP capabilities

Default deny for transfer and model egress.

A bound MCP server requires an explicit write capability. Remote transfer and AI model egress are separate capabilities; AI review also needs the caller’s acknowledgement. Local human confirmation receives neither capability.

$ graphoxide serve graphoxide-out/graph.json --transport stdio \
  --wiki-root . --allow-wiki-write \
  --allow-wiki-network --allow-wiki-model-egress
