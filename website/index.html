Get started

One binary.
Three commands.

Graphoxide is a self-contained executable. Install it, point it at a repository, and start exploring.

cargo install --git https://github.com/cgaspard/graphoxide graphoxide-cli

Builds the CLI from the current main branch and installs it on your Cargo PATH.

~/projects/checkout
# Build a graph from this repository

Questions, answered

Good to know.

Does Graphoxide use an LLM to analyze my code?+

No. Core extraction, clustering, querying, impact analysis, and reports are deterministic and run locally. An optional graphoxide label command can use a configured API only to create friendlier community names.

Is the binary really standalone?+

Yes for core use: it requires no Python, Node.js, JVM, parser downloads, account, or network connection. Release binaries are platform-specific. Git integration needs Git, and PR-aware MCP tools need the GitHub CLI.

Which languages are supported?+

Graphoxide includes compiled parsers for major languages and deterministic structured fallbacks for a broad language matrix. Unsupported text files are ignored safely.

Can I use it without VS Code?+

Absolutely. The CLI is the complete engine. VS Code is a native workspace for the same graph, while MCP and exports make it useful in many other tools.

Does the VS Code extension leave an MCP server running?+

No. The extension registers Graphoxide with VS Code and can configure detected clients. Each MCP client starts the native stdio server on demand and owns its lifecycle.

How is Graphoxide related to Graphify?+

Graphoxide is a native Rust implementation rooted in the ideas and data model of the original Graphify project. We preserve that lineage prominently and retain its Apache-2.0 and historical MIT notices.
